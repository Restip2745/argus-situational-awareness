# ARGUS

**Adaptive Real-time Global Understanding System**

一套在 3D 太陽系場景上呈現全球情勢的情報儀表板。新聞、太空動態與地緣事件經由本機 AI 分析後，標記在地球表面或對應天體的軌道位置上。

設計目標不是做成遊戲，而是借用戰情室的資訊設計手法 —— 讓使用者一眼掌握全局，而不是逐條讀新聞。

> 所有 AI 推理都在本機執行 —— 新聞內容不會送往任何雲端模型。
>
> 地圖邊界、航班、衛星、百科、行情與預測市場等公開資料仍向各自的來源即時取得，因此你正在查看哪一支股票、哪一個實體或哪一個市場，該來源會知道。

---

## 一眼讀懂的資訊設計

ARGUS 的每個事件標記都同時傳達三件事，各自使用**獨立的視覺通道**，互不干擾：

| 通道 | 表達 | 呈現 |
|---|---|---|
| **顏色** | 嚴重程度 | 危急 / 高 / 中 / 低 |
| **形狀** | 事件類別 | 九種類別各有專屬圖形 |
| **外框** | 來源可信度 | 實線＝已證實、虛線＝單一來源、點線＝未經查證 |

這代表你不需要對照圖例，就能區分「一則未經證實的危急衝突」和「一則已多方證實的中度經濟事件」—— 它們的顏色、形狀、外框全都不同。

## 核心功能

### 🌍 太陽系場景

- **完整 3D 太陽系**：30 餘個天體，依真實克卜勒軌道根數排列
- **與現實同步**：公轉、自轉、日照方向與晝夜分界線（terminator）皆對應真實時間
- **地球高解析材質**：近距離自動切換 8K 貼圖，含城市夜燈
- **程序化星雲背景**：以著色器即時生成，濃度可在設定中調整
- **貼近天體時自動正立**：北極朝上，拉遠後恢復真實軸傾角
- **距離感應的鏡頭手感**：越接近地表，旋轉越慢，避免在近距離下輕輕一動就轉過頭

| 操作 | 行為 |
|---|---|
| 滾輪 | 縮放（不會穿入天體內部） |
| 右鍵拖曳 | 環繞當前目標旋轉 |
| 左鍵拖曳 / `WASD` | 平移視角 |
| 點擊天體 | 平滑聚焦並拉近 |

### 📊 全域態勢列

畫面頂端常駐，不需點擊就能回答「現在世界是什麼狀態」：

- **態勢**：各嚴重等級的事件總數，點擊即跳至該等級最新一則
- **趨勢**：過去 6 小時與前 6 小時的類別消長
- **節奏**：24 小時進件量長條圖，依嚴重度著色
- **覆蓋**：來源數、AI 服務狀態、最近一次進件距今多久
- **商品**：布蘭特、西德州、黃金、銅的當日漲跌（詳見下方「市場資料」）

兩種原油都放，是因為兩者的價差本身就是訊號 —— 它區分「區域性供給問題」與「全球性供給問題」。

### 🕐 時間回顧

底部時間軸可拖曳回溯過去 24 小時。**整個介面跟著回到那個瞬間** —— 事件列表、態勢統計、地圖著色、甚至天體位置與日照都會一起回捲。

即時性圖層（航班、衛星、船舶）在回顧模式下會自動隱藏，因為它們只有「現在」的位置，沒有歷史軌跡。

### 🗺 地圖模式

地表著色一次只用一種，避免多重填色互相干擾：

| 模式 | 呈現 |
|---|---|
| **無** | 僅顯示邊界輪廓 |
| **政治** | 中性四色分區，純粹為了辨識，不帶任何含意 |
| **態勢** | 各國最嚴重的現行事件等級 |
| **活動量** | 各國事件數量的漸層濃度 |

### 📡 疊加圖層

可同時開啟，因為點與線不會爭奪地表：

- ✈️ **航班**（ADS-B 即時位置）
- 🛰 **衛星**（TLE 軌道推算）
- 🚢 **船舶**（AIS）
- ⚔️ **衝突前線**
- 📍 **標記與連線**（自行在場景上釘選、連結、註記）

### 🗂 情報面板

點擊任何東西都會打開對應面板，並可**獨立彈出成單獨視窗**放到第二螢幕：

- **事件面板** —— 標題與摘要、相關事件時間軸、涉入方、標籤、來源連結、縮圖；可加註個人筆記、加入書籤、匯出為 Markdown。牽涉商品市場或上市公司時，會多出對應的行情列
- **地區面板** —— 分成「概況／事件／背景」三個分頁：國旗與基本資料、穩定度、經濟結構、該國股市指數、維基百科摘要，以及該地區的完整事件清單
- **天體面板** —— 物理數據與百科摘要
- **實體面板** —— 人物、組織、地點的百科資料，可搜尋、可同時比對多個；若該實體是上市公司，會列出各市場的收盤價
- **多實體情境** —— 把最多 8 個事件、人物、地區、天體收集在一起，向 AI 提問它們之間的關聯。除了各面板上的收集按鈕，也可以直接在提問框裡用 `@` 指名：國家、報導提到的人物與事件會即時列出，feed 沒提過的名字則退回維基百科搜尋

### 🤖 本機 AI 分析

- **自動分類**：每則新聞由本機模型判定類別、嚴重度、地理位置、涉入方與可信度
- **座標解析**：模型大約有一半的地面事件只給得出地名而給不出座標，所以地名會在分類當下經
  伺服器地名表（`server/src/data/gazetteer.ts`）解析成座標並寫入資料庫，前端只負責讀取。
  每筆事件都帶一個 `geo_precision` 標明來源：`exact`（模型給的點）、`centroid`（由地名查出）、
  `region`（「歐洲」「Global Tech Sector」這類真實範圍，但沒有單一座標）、`none`（無法解析）。
  `region` 與 `none` 分開記錄是刻意的 —— 前者是「不該有圖釘」，後者是「該有但沒查到」。
  既有資料可用 `cd server && npx tsx ../scripts/backfill-geo.ts --dry-run` 檢視、去掉旗標後回填。
- **面板對話**：每個面板都能就當前主題提問，並附有自動生成的建議問題
- **畫面分析**：可截取當前場景交給多模態模型解讀
- **定期簡報**：定時彙整當前高熱度事件成情勢摘要

### 📈 市場資料

市場數字散落在四個地方，各自回答不同的問題：

| 位置 | 顯示 | 回答的問題 |
|---|---|---|
| **全域態勢列** | 原油、黃金、銅 | 世界現在的緊張程度 |
| **地區面板** | 該國股市指數 | 這個國家的市場怎麼樣 |
| **實體面板** | 公司各市場掛牌價 | 這家公司值多少 |
| **事件面板** | 相關商品、運價、涉入的上市公司 | 這則報導碰到哪些市場 |

四處共用同一套規矩：

- **每一列都帶日期。** 收盤價在非交易時段不是「現在」，跨時區時甚至不是今天。倫敦收在 +3.5%、紐約收在 −4.9% 的兩列可以同時成立，差別只在一個是當日、一個是前一盤 —— 沒有日期，那兩列看起來就是在互相矛盾。
- **不宣稱因果。** 事件面板標示「自」的變化，是把「報導發表時的收盤價」和「現在」兩個事實並列，不是說這則事件造成了那個變動。
- **查不到就整塊不顯示。** 沒有錯誤訊息、沒有佔位空格 —— 讀者沒問的東西不欠他一個錯誤。
- **代號一律由 Wikidata 推導，不由模型產生。** 幻覺出來的代號會渲染成一個完全正常的價格，只是屬於另一家公司。

**幾個刻意的取捨**

商品連結由本機模型判定，準確度隨你選用的模型而異。因此那一區顯示的是「市場」而不是「結論」—— 判斷錯了，讀者付出的代價應該止於愣一下。

運價以期貨 ETF 代表（油輪 `BWET`、乾散貨 `BDRY`），並在列下註明。真正的指數取不到：BDI 由 Baltic Exchange 授權，SCFI 與 Drewry WCI 是週更的網頁。運價的價值不在即時警報而在**確認** —— 油價幾小時內就反應，運價要兩三週，回答的是「這次干擾撐不撐得住」。

指數列沒有幣別欄，因為指數是點數不是錢；標普不是七千美元。

### 🎲 預測市場

上面那些數字全都是**回頭看**的：收盤價，以及它跟前一盤差多少。但這個介面追蹤的九個類別裡，只有經濟類找得到對應的掛牌標的 —— 選舉、停火、利率決議、發射窗口，世界上沒有那支股票。

預測市場面板補的就是這一格：一個具名未來事件的**市場定價**。清單維護在 `server/src/config/predictionMarkets.ts`，是人工挑的，沒有自動配對。

**為什麼不做自動配對** —— Polymarket 的市場是開放式的自由文字問句。要把一則新聞接到一個市場，只能靠文字相似度或模型判斷，而配錯的市場會渲染成一則報導旁邊一個完全正常的「73%」。這跟上面「代號一律由 Wikidata 推導」擋的是同一種錯誤，只是商品類別是六個列舉值、市場問句不是。手挑清單也順便讓不該出現在新聞旁邊的題目（傷亡人數、死亡賭盤）從一開始就進不來。

面板上的規矩：

- **問句原文照登，不改寫、不縮成標題。** 兩個問法幾乎一樣的市場，差別往往只在結算條件，而那個差別只存在於用字裡。
- **寫「市場定價」不寫「機率」。** 中間隔著手續費、資金成本與 longshot bias。面板陳述它有的事實 —— 最後一筆成交付了多少 —— 不替讀者做那個推論。
- **成交量過低的市場整列丟掉。** 幾百鎂的市場跟幾百萬鎂的市場長得一模一樣，而且前者通常數字更聳動，因為推動它幾乎不用錢。
- **可以連出去，但只能連出去。** 每一列的問句本身就是連到來源市場頁的連結，讓讀者自己去核對結算條件與深度。沒有錢包、沒有下單流程、沒有任何交易介面。

**時間軸會一起回捲。** 航班、衛星、船舶在回顧模式下隱藏，因為它們只有「現在」的位置；而 24 小時交易的市場在凌晨三點確實有一個價格，所以這些列留著並回到當時的定價。回捲時當日漲跌會**重新計算**成「截至那個瞬間的前 24 小時」，而不是沿用即時的那個數字 —— 六小時前的價格配上算到現在的漲跌，是兩個不可能同時成立的數字。

### 🔍 篩選與檢索

- 九個類別開關，各自顯示事件數
- 時間範圍（預設 6 小時，讓開啟畫面呈現「當下」而非積壓的歷史）
- 全文搜尋
- 書籤 / 關注清單
- 排序：最新 / 熱度 / 嚴重度
- 篩選組合可存成預設集重複套用

### 🌐 雙語

介面、事件標題與摘要皆為**中英雙語並存**。切換語言是即時的欄位切換，不需要重新分析或等待。

### ⚙️ 個人化

介面縮放、啟動視角、裝飾動效開關、警報音效與音量、星雲濃度、語言 —— 全部可在設定中調整並保留。

**漲跌顏色**可在「綠漲紅跌（美／歐）」與「紅漲綠跌（台／日）」之間切換，預設為前者。這不是喜好問題而是慣例問題 —— 讀慣其中一種的人看另一種會瞬間讀反。

另有 **精簡模式**（收合側欄）與 **沉浸模式**（全螢幕場景，僅保留浮動工具列）。

## 事件分類

| 圖形 | 類別 | 涵蓋範圍 |
|---|---|---|
| ⚔ | `ARMED_CONFLICT` | 武裝衝突、軍事行動 |
| ⚑ | `POLITICAL` | 選舉、政變、外交、制裁 |
| ◆ | `ECONOMIC` | 市場、貿易、能源價格 |
| ☰ | `SOCIAL` | 社會運動、示威、人道危機 |
| ⚛ | `SCIENCE_TECH` | 科技突破、AI 發展、研究 |
| ❋ | `ENVIRONMENT` | 氣候事件、自然災害 |
| ✚ | `HEALTH` | 疫情、公衛事件 |
| ⬡ | `CRIME_SECURITY` | 網路攻擊、恐怖主義、跨國犯罪 |
| ✦ | `SPACE` | 太空任務、星際天體、撞擊預警 |

事件的存活時間由**熱度分數**決定，而非固定期限：高嚴重度、多方證實、或持續被後續報導提及的事件會自動延長保留，冷卻的事件則較快淘汰。

## 快速開始

需要 [Ollama](https://ollama.com) 在本機執行。

```bash
ollama pull gemma4:e4b
```

```bash
npm install
cp .env.example .env
npm run dev
```

前端啟動於 `http://localhost:5173`，後端於 `3001`。RSS 來源清單維護在 `server/src/config/feeds.ts`，不需要任何 API 金鑰。

> Windows 若 `better-sqlite3` 編譯失敗，需安裝 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) 並勾選「使用 C++ 的桌面開發」。

船舶圖層需要 [aisstream.io](https://aisstream.io) 的免費金鑰（`AISSTREAM_API_KEY`），未設定時該圖層停用，其餘功能不受影響。

| 資產 | 來源 | 授權 |
|---|---|---|
| 行星、月球、太陽貼圖 | [Solar System Scope](https://www.solarsystemscope.com/textures/) | CC BY 4.0 |
| 地球夜間城市燈光 | [NASA Visible Earth](https://visibleearth.nasa.gov/) | Public Domain |
| 土星環材質 | [Planet Pixel Emporium](http://planetpixelemporium.com/) | 個人使用免費 |
| 政治邊界 | [Natural Earth](https://www.naturalearthdata.com/) | Public Domain |
| 百科資料 | Wikipedia REST API | CC BY-SA |
| 股票代號對應 | Wikidata（`P414` 交易所 / `P249` 代號） | CC0 |
| 行情與指數 | Yahoo Finance chart 端點 | 非官方、無需金鑰，隨時可能失效 |
| 預測市場 | Polymarket Gamma / CLOB | 公開唯讀、無需金鑰、無需錢包 |
| 航班 / 衛星 | OpenSky Network · Celestrak | 各自條款 |

**關於行情**：Yahoo 的 chart 端點沒有公開文件也沒有版本保證，這裡把它當成隨時會壞的東西看待 —— 解析層對每一種非預期的回應都失敗成「不顯示」，而不是顯示一個看起來正常的錯誤數字。要換資料源的話，`server/src/services/market.ts` 是唯一需要改的地方。

**關於預測市場**：只讀取公開的市場價格，不連錢包、不下單、不提供任何交易介面 —— 面板唯一的互動是連到來源市場頁。取用的端點見 `server/src/services/prediction.ts`，換資料源只需要改那裡。

**這不是投資工具**：收盤價都是延遲的，預測市場的定價也不是機率。所有數字的用途都是替新聞提供脈絡，不構成任何建議。

**關於邊界**：Natural Earth 採實際控制（*de facto*）原則標示，而非任何單一國家或國際組織的官方立場。台灣、克里米亞、喀什米爾、南海島礁等爭議區域的描繪均沿用其資料集，本專案未做政治性調整。
